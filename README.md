# Keia (Кея) v2.1

Keia — это локальный (или облачный) AI-компаньон с ярко выраженным характером агрессивной цундере, долговременной памятью, системой отношений и способностью к проактивному общению. Она живет в Discord, помнит ваши разговоры, ведет дневник и не стесняется в выражениях.

# Особенности

- Живой характер: Жесткая, нарциссичная цундере. Использует японские ругательства (бака, ахо), мат, черный юмор и ролевые действия (`-*закатывает глаза*-`).
- Долговременная память: 
  - Извлекает и запоминает факты о вас (имя, привычки, любимый кофе).
  - Ведет личный дневник (суммаризация дня).
  - Имеет «Блокнот» для будущих событий (если вы скажете «скоро придут гости», она запомнит).
- Система отношений и ревность: У каждого пользователя есть уровень симпатии (от -100 до 100). Если вы (создатель) общаетесь с другими девушками, она может приревновать. А к незнакомцам будет относиться свысока.
- Поиск в интернете: Умеет гуглить погоду и новости. Но если вы ей не нравитесь (низкий уровень симпатии), она пошлет вас... искать самостоятельно.
- Реакции и картинки: Понимает мемы, гифки и картинки (благодаря Gemini Flash). Может ставить реакции (эмодзи) на ваши сообщения.
- Проактивность: Если вы долго молчите, она может написать вам первой, вспомнив ваши прошлые темы.

# Требования

- Python 3.10+
- Токен Discord-бота (получить в [Discord Developer Portal](https://discord.com/developers/applications))
- API-ключ от любого OpenAI-совместимого провайдера. Рекомендуется модель `google/gemini-2.5-flash`.

# Установка и запуск
1. Клонируйте репозиторий:
   git clone https://github.com/KeAiAda/keia-v2.git
   cd keia-v2

2. Создайте виртуальное окружение и установите зависимости:
  python -m venv .venv
  source .venv/bin/activate  # Для Linux/macOS
  # или .venv\Scripts\activate для Windows

  pip install -r requirements.txt

3. Настройте переменные окружения: 
  Скопируйте шаблон .env.example в .env:
  cp .env.example .env
  Откройте .env любым текстовым редактором и заполните:
    DISCORD_TOKEN — токен вашего бота.
    OWNER_ID — ваш Discord ID (чтобы Кея знала, кто тут главный).
    LLM_API_KEY — ваш ключ от нейросети.

4. Можно запускать (из директории проекта): 
  python main.py 

# Кастомизация:
Если вы хотите, чтобы бот общался в другом стиле (например, был заботливым дворецким или милой аниме-девочкой), вам не нужно переписывать код. Достаточно отредактировать файлы в папке core/prompts/:
    persona.txt — базовый характер, внешность и эго.
    style.txt — правила речи (мат, эмодзи, длина сообщений).
    examples.txt — примеры диалогов (это самый важный файл, модель копирует стиль из него).

# Структура проекта: 
keia-v2/
├── core/           # Ядро (мозг, память, работа с LLM)
│   ├── prompts/    # Тексты промптов (характер, стиль, примеры)
│   ├── agent.py    # Сборка контекста и генерация ответа
│   ├── facts.py    # Долговременная память (факты)
│   ├── events.py   # Блокнот (будущие события)
│   ├── journal.py  # Дневник
│   ├── relationships.py # Система отношений
│   └── ...
├── ui/             # Интерфейсы
│   └── discord_bot.py # Логика Discord-бота
├── memory/         # Локальное хранилище данных (факты, логи, история)
├── main.py         # Точка входа
├── requirements.txt
└── .env.example

# Важно!
Бот использует мат и оскорбления в рамках ролевой игры. Убедитесь, что вас и ваших друзей это не оскорбляет. Используйте с осторожностью на публичных серверах.
