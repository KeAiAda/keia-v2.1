# Keia (Кея) v2.1

**Keia** — это локальный (или облачный) AI-компаньон с ярко выраженным характером агрессивной цундере, долговременной памятью, системой отношений и способностью к проактивному общению. Она живет в Discord, помнит ваши разговоры, ведет дневник и не стесняется в выражениях.

## Особенности

- **Живой характер:** Жесткая, нарциссичная цундере. Использует японские ругательства (бака, ахо), мат, черный юмор и ролевые действия (-*закатывает глаза*-).
- **Долговременная память:** 
  - Извлекает и запоминает факты о вас (имя, привычки, любимый кофе).
  - Ведет личный дневник (суммаризация дня).
  - Имеет «Блокнот» для будущих событий.
- **Система отношений и ревность:** У каждого пользователя есть уровень симпатии (от -100 до 100). Если вы (создатель) общаетесь с другими девушками, она может приревновать.
- **Поиск в интернете:** Умеет гуглить погоду и новости. Но если вы ей не нравитесь, она пошлет вас искать самостоятельно.
- **Реакции и картинки:** Понимает мемы, гифки и картинки (благодаря Gemini Flash). Может ставить реакции (эмодзи) на ваши сообщения.
- **Проактивность:** Если вы долго молчите, она может написать вам первой.

## Требования

- Python 3.10+
- Токен Discord-бота (получить в [Discord Developer Portal](https://discord.com/developers/applications))
- API-ключ от любого OpenAI-совместимого провайдера. Рекомендуется модель google/gemini-2.5-flash.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KeAiAda/keia-v2.1.git
   cd keia-v2.1

2. **Создайте виртуальное окружение и установите зависимости:**
  ```bash  
  python -m venv .venv
  source .venv/bin/activate  # Для Linux/macOS
  .venv\Scripts\activate     # Для Windows
  pip install -r requirements.txt

3. **Настройте переменные окружения:**
  Скопируйте шаблон .env.example в .env:
  ```bash  
  cp .env.example .env
   
   Откройте .env и заполните:
   - DISCORD_TOKEN — токен вашего бота.
   - OWNER_ID — ваш Discord ID.
   - LLM_API_KEY — ваш ключ от нейросети.

4. **Запустите:**
  ```bash
  python main.py

## Кастомизация

Если вы хотите, чтобы бот общался в другом стиле (например, был заботливым дворецким или милой аниме-девочкой), вам не нужно переписывать код. Достаточно отредактировать файлы в папке core/prompts/:
- persona.txt — базовый характер и внешность.
- style.txt — правила речи.
- examples.txt — примеры диалогов (самый важный файл, модель копирует стиль из него).

## Важное предупреждение

Бот использует мат и оскорбления в рамках ролевой игры. Убедитесь, что вас и ваших друзей это не оскорбляет. Используйте с осторожностью на публичных серверах.
